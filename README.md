# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/803946fa-2fa0-4237-bcb1-30ba15381e98

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy [.env.example](.env.example) to `.env.local` and replace the placeholder value with your Gemini API key
3. Run the app:
   `npm run dev`
